# 可直接填空的派工模板

所有模板交付預設：新檔寫指定 output；修改既有檔必須先備份。回報合約統一為：`狀態 PASS/FAIL/NOT_VERIFIED｜最多五點結論｜證據 檔案:行號 或官方URL｜測試命令與結果｜限制｜产物絕對路徑`，上限 500 字。未執行測試必須寫未執行。禁止帶原始憑證。填完仍有必要欄空白，先補齊再派。

## 搜尋
```text
task_id：{ID}；model：{目前schema合法ID}；effort：{合法值}；attempt：{0/1/2}
目標與動機：找出{符號/檔案/版本}以決定{具體決策}。
範圍：{repo絕對路徑或已確認owner/repo+commit}；來源：{已知檔/關鍵字}。
允許：只讀；輸出新檔{output}；不掃{排除目錄}。
方法：先檔名/rg，再讀相關範圍；最多{查詢數}次。遇截斷縮小範圍。
驗收：每個候選附位置、為何匹配；有/無/未確認分開；空結果列實際查詢覆蓋，不能宣稱全repo不存在。
回報：按統一合約；不得貼全文。
```

## 實作
```text
task_id：{ID}；model：{ID}；effort：{值}；attempt：{0/1/2}
目標與動機：讓{輸入}產生{可觀察行為}，解決{已重現問題}。
來源/基線：{commit/hash}；輸入：{需求/失敗測試路徑}。
可寫路徑：{檔案清單}；禁止改：{範圍}；備份至{唯一backup路徑}。
驗收：正例{fixture/預期}；反例{fixture/預期}；回歸{必要命令}。
邊界：不部署、不用真實憑證；相容性要求{介面/資料保留}。
輸出：{patch/說明/測試結果路徑}。失敗記錄實際命令及假設；不得自改驗收規則使測試通過。
回報：按統一合約；作者通過後仍由獨立代理驗收。
```

## 重構
```text
task_id：{ID}；model：{ID}；effort：{值}；attempt：{0/1/2}
目標與動機：將{模組責任}分離，降低{具體耦合/重複}。
基線：{commit/hash}；允許修改{路徑}；修改前備份至{路徑}。
不變契約：{公開函式/輸入輸出/持久化格式/錯誤行為}。
驗收：重構前先記{代表性行為fixture}；重構後相同fixture與必要負例一致；差異清單為空或逐項有授權依據。
不得夾帶功能或相似度算法更動。發現安全問題另落{backlog}，不默默改數學語義。
輸出：{新責任圖/patch/測試log路徑}；回報按統一合約。
```

## 研究
```text
task_id：{ID}；model：{ID}；effort：{值}；attempt：{0/1/2}
目標與動機：比較{最多幾個選項}以決定{下一步}。
已知條件：{用途/地區/版本/預算/時間}；本次不做{整合或購買}。
來源：先官方文件{入口}；需查當日內容{auth/價格/涵蓋}。
驗收：每選項列用途、認證、格式、限制、官方URL、查核日期；文件證實/實測/未知分欄；來源衝突原樣記錄，不猜。
禁止將私人案件、密鑰或內部程式上傳搜尋網站。只用公開/合成範例。
輸出{研究檔}；回報按統一合約。無關搜尋停止，未解存明確依賴。
```

## 審查（fresh context）
```text
task_id：{ID}；fork_turns：none；model：{ID}；effort：{值}
目標與動機：獨立判定{產物}是否滿足{需求}，不假設作者正確。
輸入：需求{路徑或完整文字}、產物{絕對路徑}、原始來源{路徑/hash}。
權限：只讀原始檔；審查結果寫新檔{output}；不代作者修改。
驗收：逐檔read-back；驗連結/路徑/工具schema；找規則矛盾、模糊詞、錯誤完成宣稱；程式依{命令}重跑，查正反例；安全結論核對攻擊前提、資料流與實跑程度。
回報：PASS/FAIL/NOT_VERIFIED；缺陷按阻塞/重要/輕微排列，每項附檔案:行號、失敗場景、最小修法。無缺陷仍列覆蓋與未測，不寫無条件保證。
```
