## 三件最重要但容易沒被問到的事
1. **資料身份比模型換代更先決。** 原程式會把同 patent id 的舊 label 移到新 claim/citation；舊分數也能配新輸入。先修不可變結果快照、pair identity與標籤失效機制，再談更強 embedding 或 isotonic。案例與負例在 evidence/SECURITY-REVIEW.md。
2. **分數不是法律結論。** UI 的 SEP 與資料的 highly_relevant 並不等義。定義到底預測「檢索相關」「特徵覆蓋」或「法律必要性」，再建立標籤與獨立驗證集。不要讓 min gate 或八筆校準樣本替代請求項及標準的證據判斷。
3. **未來執行效力需要安裝與回讀。** 此包放在哪裡不等於下回模型就會載入。先確認實際 repo、放在受工具支援的入口，再請新session回報讀到的規則與來源。移往 Claude 時重新查模型ID/effort，不照抄 Codex schema。
