# EXAMINER 知識蒸餾庫

本目錄保存由審查官確認的規則來源與回歸標籤。原始 OA／請求項／引證語料不在這裡被改寫；執行時只讀取輸入並產生衍生分數與 Audit Trail。

## 目錄

- `teacher-approved/`：教師確認的 JSON 規則與標籤（權威來源）。
- `cases/`：逐案蒸餾說明，檔名為案件編號。
- `../rules/examiner-rules-v4.js`：瀏覽器與 Node 可直接執行的靜態規則編譯結果。
- `../rule-engine-v4.js`：離線、確定性的 v4 影子評分器。

## 評分與法律層分離

- 技術覆蓋率：`0.4 × Element Average + 0.6 × Element Minimum`。
- 功能等效不是文字同義；需符合規則的技術語境、訊號／動作與防誤判條件。
- 多文獻組合若未由審查官確認 combination gate，最高只給暫定 75 分。
- 「AI 取代控制器」只屬進步性推論，不冒充單一文獻直接揭露。
- 專利法第 26 條問題以獨立旗標輸出，不拿來增減先前技術相似度。
- 先前技術日期資格另行檢查，規則引擎預設輸出 `unchecked`。

## 上線策略

目前是 `v4.0.0-shadow.1`。正式分數仍由 v3.10 產生；v4 結果同步顯示並寫入驗證資料庫。待同一批案件完成 A/B 比較、確認 False High／False Low 改善後，再另行核准切換正式分數。
