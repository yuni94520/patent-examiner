# 110135148 教師蒸餾紀錄

## 教師結論

本案是「多文獻結合核駁」正例。引證 1 提供偽三埠／雙讀取埠 SRAM 的主體架構；引證 2、3、4分別補入寫入埠、傳輸閘、字元線或控制細節。組合後可達到 HIGH，但單一引證不得假裝已揭露全部必要元件。

## 核心規則

1. `primary sense amplifier / inverter stage -> NAND or first logic gate` 是功能等效轉換，不是字典同義詞。必須驗證輸入、輸出極性、真值功能與訊號路徑；完整成立時 0.90，僅有一般功能近似時 0.82。
2. `two independent paths -> complementary differential pair` 僅在可形成互補值、可由共同感測關係解讀，且請求項不要求兩埠執行互不相關的同步交易時成立；正向 0.85，反向 0.72。
3. `upper/lower sub-module group -> upper/lower group` 為用語等效，1.0。
4. `write enable + group selection -> asserted write-mux address/control` 為組合訊號到控制功能的對應，0.90。
5. 寫入埠與傳輸閘是由次要引證補入的模組。只有通過 `COMBINATION_GATE_001` 才可補足至 1.0。

## 雙軌分數

- 單一引證：保留寫入埠／傳輸閘缺口，不能判定新穎性完全命中。
- 多引證組合：教師元件分數 `[100, 90, 100]`，`mean=96.6667`、`min=90`、`fused=92.6667`，標籤 `HIGH`；法律標籤另記為 `OBVIOUS_COMBINATION`。
- 單純 AND／反相級改為 NAND 的局部轉換可為 `82`、`MID_HIGH`，但仍可因簡單變更而得到 `OBVIOUS_SIMPLE_CHANGE`。這證明法律結論不能直接等同相似度標籤。

## 防誤判

- 不得把所有放大器都視為 NAND。
- 若兩埠要求不同地址或同時獨立操作，不得轉成互補差動對。
- 「同屬 SRAM」只是支持因素，不是組合動機的充分條件。
