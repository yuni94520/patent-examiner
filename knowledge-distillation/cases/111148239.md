## 可重用規則

- `設備唯一識別符／由設備導出的串 -> 節點指紋`：在設備綁定語境中可視為直接功能等效，分數 100。
- `綁定字串修改白箱實施且僅在合法設備輸出正確結果 -> 軟鎖定白箱`：須同時具備設備綁定、白箱修改及合法設備正確輸出三個條件，分數 100。
- `第一函數與第二函數的編解碼級聯 -> 節點 LUT 與全域 LUT 的明確分工`：只能作進步性推論，分數 85；不得標示為直接揭露。
- `中心伺服器／KMS 分發多個金鑰 -> 含複數機密的基底檔案`：只能作進步性推論，分數 85。
- `綁定串作用於全域密鑰 -> 節點特定鎖定轉換產生節點已編碼機密`：若未明示獨立轉換步驟，只能作進步性推論，分數 85。
- `實體設備部署 -> 虛擬機器實例部署`、`白箱對稱密碼 -> 非對稱金鑰／憑證／簽章／雜湊應用`：均屬用途或部署替換，原則分數 85，且須排除特殊隔離架構或無法預期功效。
- `伺服器分發 -> 節點間 P2P 傳遞`及`單一處理器 -> 雙處理器／雙記憶體安全分工`：均只能作部署拓樸或硬體配置的進步性推論，原則分數 85。

## 衝突與防誤判

- 若引證明示白箱實施在所有設備均相同、沒有設備綁定，不得對「節點指紋／軟鎖定」給高分。
- 「可適用於非對稱密碼」不等於直接揭露「產生金鑰對、產生憑證、對私鑰節點編碼」的完整程序。
- 「第一／第二函數」不當然等於「節點特定 LUT／跨節點全域 LUT」；需要白箱、LUT 或等價查表網路的語境守門。
