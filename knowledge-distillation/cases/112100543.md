# 112100543 傳呼早期指示位置決定

## 來源與結論

來源為 2026 年 8 月 31 日第二次審查意見書，引用 US20120122495A1。審查判斷認為請求項 1 至 30 均欠缺進步性。引證已直接揭露早期傳呼指示配置、在傳呼時機前監測或發送 PEI、PDCCH 與傳呼時機的關聯；主要差異是如何從多個傳呼訊框中選定參考 PF，並以訊框與符號層級偏移、模函數或索引規則計算 PEI 位置。

## 可重用規則

- `提前於 PO 的 EPI／PEI 配置與監測 -> 傳呼早期指示配置及監測`：具網路配置、傳呼時機及提前監測三項語境時，可視為直接功能等效，分數 100。
- `提前量／時序偏移 -> 從多個 PF 選定參考 PF 並決定 PEI 位置`：引證沒有參考 PF，僅能作時序錨點的進步性推論，分數 85。
- `OFDM 符號區間加上傳呼前提前量 -> 訊框級與符號級兩階段偏移`：只能作階層式時序拆解的進步性推論，分數 85。
- `已知 PMO 及偏移 -> 逆向推導參考 PF`、`一組候選 EPI 位置 -> 評估候選位置以辨識參考 PF`：均為進步性推論 85，不得標示成逐字揭露。
- `EPI 為負或不存在時進入低耗能／預設檢查 PO -> 無法辨識時跳過 PO 或忽略 PEI 的回退機制`：功能等效分數 95，但必須保留省電與防漏傳呼兩種相反策略。
- `廣播位置與配置／UE search space -> PMO 週期及偏移的搜尋空間集配置`、`第一 PMO 作錨點`：屬進步性推論 85。
- `SFN 或 PF index 搭配週期／數量 -> 模函數定位參考 PF`、`奇偶索引選取`：屬通訊排程的常規數學推論 85。
- `UE 監測流程 <-> 網路端發送流程`：只有在相同 PEI 訊息與時序關係下，才可作對向角色鏡射，分數 90。

## 衝突與防誤判

- 引證僅揭露「在 PO 前某時刻」而沒有多 PF 或參考 PF 時，不得直接給「辨識參考 PF」高分。
- `一組可能的 EPI 位置`不等於已直接揭露候選評估演算法。
- `Paging cycle`或`DRX cycle`本身不等於 SFN modulo、PF index modulo 或奇偶索引規則。
