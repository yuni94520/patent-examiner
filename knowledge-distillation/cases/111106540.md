# 111106540 教師蒸餾紀錄

## 教師結論

本案是「主體架構 + 精確缺失限制」的組合正例。US20190287629A1 提供非揮發性記憶體陣列、複數頁緩衝器與控制邏輯；US20110208905A1 補入命令指定 `n` 個緩衝器子集並在該子集中傳輸資料負載。

## 規則

- `NVM array + plural page buffers + controller` 與 `command explicitly selects subset of n buffers for payload` 通過組合閘後，對請求項 1 的必要限制給 1.0。
- 同一操作族可展開為：shift-in、media-write、media-read、shift-out、unique buffer identifier，以及 controller-buffer 與 subset-array 的平行傳輸。
- 附屬限制如每單元位元數、SoC 控制器、SLC/pSLC/MLC/TLC/QLC/VLC、CUA NAND，必須各自保存來源引證，不能因基本架構已成立就自動補齊。

## 組合門檻

同屬記憶體儲存系統及同具緩衝器控制，只是支持資料。真正放行條件是：次要引證精確供應已識別的缺失限制、介面相容、功能方向一致、存在可說明的採用理由，且沒有改變主要運作原理。

## 分數

請求項 1 教師元件分數 `[100, 100, 95]`，`fused=96.3333`、`HIGH`；法律標籤 `OBVIOUS_COMBINATION`。
